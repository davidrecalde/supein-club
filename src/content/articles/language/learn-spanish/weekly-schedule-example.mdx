# スペイン語独学スケジュールの例：1週間のルーティン

「何を勉強すればいいか分からない」という悩みは、学習計画そのものより、日々の実行段階でつまずくことのほうが多いです。ここでは、曜日ごとに技能を分散させた、現実的な1週間のスケジュール例を紹介します。自分のレベルや生活リズムに合わせて調整してください。

## 1週間のスケジュール

| 曜日 | 内容 | 目安時間 |
|---|---|---|
| 月曜日 | 新しい文法 | 30分 |
| 火曜日 | 語彙＋フラッシュカード | 20分 |
| 水曜日 | リスニング（ポッドキャスト） | 30分 |
| 木曜日 | 文法の復習 | 20分 |
| 金曜日 | ライティング（日記） | 30分 |
| 土曜日 | スペイン語での娯楽（ドラマ／音楽） | 1時間 |
| 日曜日 | 休息、または軽い復習 | — |

## なぜこの配分が効果的なのか

一つの技能だけに集中し続けると、飽きやすく、バランスの悪い力になりがちです。このスケジュールは、インプット（文法・語彙・リスニング）とアウトプット（ライティング）、そして楽しみながら学べる時間（土曜日の娯楽）をバランスよく組み合わせています。

- **月・木：文法。** 新しい内容を学んだ数日後に復習することで、間隔を空けた反復の効果が得られます。
- **火：語彙。** フラッシュカードは、短時間で単語を定着させるのに効果的なツールです。
- **水：リスニング。** 耳を慣らすことは、他の技能とは違う独自の練習が必要です。
- **金：ライティング。** 日記のように、自分の生活に関する短い文章を書くことで、学んだ文法と語彙を実際に使う練習になります。
- **土：娯楽。** スペイン語のドラマや音楽を楽しむ時間は、「勉強」という感覚を減らしながら、自然にスペイン語に触れる貴重な機会です。
- **日：休息。** 継続のためには、意図的に休む日を作ることも大切です。無理に毎日詰め込むと、長続きしません。

## 自分に合わせてカスタマイズする

このスケジュールはあくまで一例です。仕事や学業の都合に合わせて、曜日や時間配分を入れ替えても構いません。大切なのは、**技能をバランスよく分散させること**と、**現実的に続けられる量に抑えること**です。
