## レベル診断テスト（全60問）

<LevelTestCard levelTest={frontmatter.levelTest} />

しばらくスペイン語を勉強しているけれど、今どのくらいのレベルなのか分からない——そんな方のために、無料で受けられる診断テストを用意しました。**A1からC2まで、少しずつ難しくなる60問**に答える形式で、文法・語彙・読解・聴解をチェックします。登録は不要で、答え終わるとその場で、[欧州言語共通参照枠（CEFR）](https://cvc.cervantes.es/ensenanza/biblioteca_ele/marco/cap_03.htm)に沿ったレベルの目安と、レベル別の正答数、次に学ぶべき内容がわかります。

---

## テストの受け方

やり方はシンプルで、一人で完結できるように設計されています。

1. **「テストを始める」を押します。** 問題は1問ずつカードで表示され、答えを選ぶと次の問題に進みます。正解かどうかは、テストの途中では表示されません。
2. **わからない問題は「わからない」を選びます。** 当てずっぽうで答えるより、今の実力に近い結果が出ます。
3. **音声問題は2回まで聞けます。** 音を出せないときは「最後に回す」を選ぶと、その問題をテストの最後に回せます。
4. **途中でやめても大丈夫です。** 回答はこのブラウザに自動で保存され、次に開いたときに続きから再開できます。「最初からやり直す」で、いつでもリセットできます。
5. **60問すべてに答えると、結果が表示されます。** レベル別の正答数、推定レベル、分野ごとの得意・苦手、次に学ぶユニットがわかります。全問の解説ページも開けます。

すべての問題に正解する必要はありません。後半には上級者向けの問題も出てきます。歯が立たない問題が出てきたら、そこが今のあなたの学びどころです。

## 各レベルで測っている内容

各レベル10問（文法4問・語彙3問・読解1問・聴解2問）で、[セルバンテス学院のカリキュラム大綱（PCIC）](https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/indice.htm)に基づき、そのレベルを特徴づける項目から出題しています。テスト中は、どのレベルの問題かは表示されません。

- **A1 Acceso：** 冠詞と名詞の性、ser と estar、hay、gustar、曜日や食事の基本語彙、短い自己紹介文の読解、時刻や自己紹介の聞き取り。
- **A2 Plataforma：** 点過去・線過去・現在完了の使い分け、比較、道案内の表現、過去の出来事を書いた文の読解、駅のアナウンスや週末の話の聞き取り。
- **B1 Umbral：** 接続法現在、過去完了、por と para、談話標識、ser と estar で意味が変わる形容詞、意見を述べる文の読解と会話の聞き取り。
- **B2 Avanzado：** si + 接続法過去の条件文、時制の一致、aunque + 接続法、再帰受動の se、慣用表現、改まったメールの読解、ラジオのニュースの聞き取り。
- **C1 Dominio operativo eficaz：** 法による意味の違い、アスペクト、関係詞 lo cual、コロケーション、口語、皮肉や遠回しな言い方の理解。
- **C2 Maestría：** 接続法未来や文語の条件文、形容詞の位置による意味の違い、ことわざ、専門的な語彙、報道文の読解、論述や皮肉を含む会話の聞き取り。

## 結果別に次にすべきこと

- **A1、または初めて受ける方：** まずは発音と読み方、名詞の性、ser と estar から。[スペイン語学習ロードマップ](/language/learn-spanish/)で全体像を確認し、[A1ハブ](/language/learn-spanish/a1/)から始めましょう。
- **A2：** 基礎はできています。[A2ハブ](/language/learn-spanish/a2/)で、いちばん定着しにくい点過去と線過去の使い分けに取り組みましょう。
- **B1：** もっとも実用的な段階です。[B1ハブ](/language/learn-spanish/b1/)で、接続法と意見の表現を固めましょう。
- **B2：** しっかりした実力があります。[B2ハブ](/language/learn-spanish/b2/)で、接続法過去と条件文、時制の一致を仕上げ、DELE B2を目標にしましょう。
- **C1・C2：** 細かなニュアンスと文体の段階です。[C1ハブ](/language/learn-spanish/c1/)・[C2ハブ](/language/learn-spanish/c2/)で、上級の表現と[DELE](/language/learn-spanish/dele/)の対策に取り組みましょう。

どの結果であっても、レベル全体の進め方は「[スペイン語をA1からC2まで学ぶ完全ロードマップ](/language/learn-spanish/)」で確認できます。

## これは公式な試験ですか？

いいえ。このテストは**あくまで目安**であり、あなたの現在地を把握し学習プランを選ぶためのものです。何かを認定するものではなく、公式試験の代わりにもならず、公式試験の形式をまねたものでもありません。大学・企業・公的機関に対してスペイン語力を証明する必要がある場合に必要なのは**DELE**（外国語としてのスペイン語検定）です。DELEはスペイン語の公式資格で、スペイン教育省に代わって[セルバンテス学院](https://examenes.cervantes.es/es/dele/que-es)が発行しています。

DELEにはA1・A2・B1・B2・C1・C2の公式レベルがあり、専用の対策が必要で、[東京セルバンテス文化センター](https://tokio.cervantes.es/es/)のような認定会場で受験します。[DELEのページ](/language/learn-spanish/dele/)では、試験の形式、どのレベルを受けるべきか、このテストとDELEの比較を解説しています。

まとめると、このテストは**現在地を知るため**に、DELEは**公式に証明するため**に使ってください。
