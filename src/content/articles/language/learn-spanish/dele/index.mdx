# DELEとは：レベル・構造・対策の始め方

**DELE**（外国語としてのスペイン語検定）は、スペイン語の運用能力と習熟度を証明する公式の資格で、スペイン教育・文化・スポーツ省に代わって[セルバンテス学院](https://examenes.cervantes.es/es/dele/que-es)が発行しています。国際的にも無期限にも有効な、唯一のスペイン語試験です。

このページはDELEクラスターのハブです。6つのレベルの全体像、共通の試験構造、そして各レベルの具体的な対策ガイドへのリンクをまとめています。DELEと西検のどちらにするか迷っている方は、[DELE vs 西検](/language/learn-spanish/dele-vs-seiken/)の比較記事をご覧ください。

---

## DELEを選ぶ理由

- **公的性：** スペイン語圏の政府・大学・企業に認められています。
- **無期限の有効性：** 他の資格と異なり、DELEは失効しません。
- **CEFRとの整合性：** 各レベルは、[欧州言語共通参照枠（CEFR）](https://cvc.cervantes.es/ensenanza/biblioteca_ele/marco/cap_03.htm)のレベルに正確に対応しています。
- **法的要件：** スペイン国籍の取得や、一部の大学への入学に義務付けられています。

---

## DELEの6つのレベル

DELEは、あなたの運用能力のレベルに応じて、6つの独立した資格に分かれています。

| CEFRレベル | DELE資格 | 使用者プロフィール |
|---|---|---|
| A1 | DELE A1 | アクセス。基礎的な理解。 |
| A2 | DELE A2 | プラットフォーム。日常的な自立性。 |
| B1 | DELE B1 | しきい値。旅行・仕事における自立性。 |
| B2 | DELE B2 | 上級。流暢さと論証力。 |
| C1 | DELE C1 | 実務運用能力。専門的・学術的な使用。 |
| C2 | DELE C2 | 最上級。ネイティブに近い精度。 |

DELEがA1からC2までの6段階に分かれているのは恣意的な区切りではありません。単語の使用頻度が示す曲線——最初は急に下降し、上のレベルほど平らになっていく形——と同じ論理に沿って、各レベルが要求する「量」から「精度」への重心の移り変わりを段階的に認定する仕組みだからです（[ジップの法則で読み解く学習ロードマップ](/language/learn-spanish/zipf-law-methodology/)）。

---

## 試験の一般構造

C2を除くすべてのDELEには4つの試験があります。

1. **読解：** さまざまな文章（ニュース、メール、記事）。
2. **聴解：** ラジオの録音、会話、講演。
3. **作文：** メール、エッセイ、報告書の作成。
4. **口頭表現：** モノローグと試験官との対話。

*注記：DELE C2は、統合課題を用いる異なる構造を持っています。*

---

## 準備の始め方

対策は、目標とするレベルによって大きく異なります。孤立した文法だけを勉強せず、試験の各技能を練習しましょう。

- **初心者（A1〜A2）：** 基礎語彙とシンプルな構造に集中しましょう。[DELE A1](/language/learn-spanish/dele/a1/)または[DELE A2](/language/learn-spanish/dele/a2/)へ。
- **中級者（B1〜B2）：** 仕事や学業に不可欠なレベルです。接続法と論証力を磨きましょう。[DELE B1](/language/learn-spanish/dele/b1/)または[DELE B2](/language/learn-spanish/dele/b2/)へ。
- **上級者（C1〜C2）：** 文体の洗練とニュアンスの習得を目指しましょう。[DELE C1](/language/learn-spanish/dele/c1/)または[DELE C2](/language/learn-spanish/dele/c2/)へ。
