# スペイン語A2文法まとめ

A2レベルでは文法が大きく前進します。**過去形の時制**、**未来形**、**目的格代名詞**、**比較表現**、**動詞の迂言的表現**を扱えるようになります。これらの内容によって、自分のルーティンを説明し、過去の経験を語り、将来の予定を話せるようになります。このページでは、[セルバンテス学院のカリキュラム大綱（PCIC）](https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/indice.htm)に基づき、ブロックごとに整理して解説します。

各ブロックには、説明・例文・解答付きのミニ練習問題がついています。現在形を復習したい方は[A1文法](/language/learn-spanish/a1/grammar/)へ、このレベル全体の見取り図が欲しい方は[A2ハブ](/language/learn-spanish/a2/)へどうぞ。

## 1. 点過去 vs 線過去

これはA2における**もっとも重要な対比**であり、日本人学習者にとって特に難しいポイントのひとつです。スペイン語には2つの主要な過去時制があり、どちらを選ぶかで意味が変わります。

### 点過去（Pretérito indefinido）

過去のある特定の時点における、**1回限りで完結した行為**を表します。

- Ayer comí paella.（昨日パエリアを食べた／完結した行為）
- Fui a Tokio el año pasado.（去年東京に行った／完結した旅行）
- Compré el libro ayer.（昨日その本を買った）

規則活用（-ar型：-é, -aste, -ó, -amos, -asteis, -aron／-er/-ir型：-í, -iste, -ió, -imos, -isteis, -ieron）：

- hablar → hablé, hablaste, habló, hablamos, hablasteis, hablaron
- comer → comí, comiste, comió, comimos, comisteis, comieron

### 線過去（Pretérito imperfecto）

過去における**継続的・習慣的・描写的な行為**を表し、行為の終わりには焦点を当てません。

- Cuando era niño, vivía en Osaka.（子どもの頃、大阪に住んでいた／描写・習慣）
- Todos los días cenaba a las 8.（毎日8時に夕食をとっていた／習慣）
- Hacía sol y la calle estaba tranquila.（晴れていて、通りは静かだった／描写）

規則活用（-ar型：-aba, -abas, -aba, -ábamos, -abais, -aban／-er/-ir型：-ía, -ías, -ía, -íamos, -íais, -ían）：

- hablar → hablaba, hablabas, hablaba...
- comer → comía, comías, comía...

### 時のマーカー（合図となる語句）

| 点過去 | 線過去 |
|---|---|
| ayer（昨日）, anteayer（一昨日） | siempre（いつも）, todos los días（毎日） |
| el año pasado（去年） | cuando era niño/a（子どもの頃） |
| el lunes pasado（先週の月曜日） | antes（以前は）, en aquel entonces（当時） |
| la semana pasada（先週） | a menudo（よく） |

> **よくある間違い：** 「Ayer comía paella」と言ってしまうこと（誤り）。ayerは特定の時点なので点過去が正解です：「Ayer comí paella」。

**ミニ練習：**
1. Ayer ___（comer）paella. → **comí**（点過去）
2. Cuando ___（ser）niño, vivía en Osaka. → **era**（線過去）
3. Todos los días ___（cenar）a las 8. → **cenaba**（線過去）

## 2. 単純未来形

単純未来形は**予測**と**意図**を表します。

### 規則活用

不定詞に-é, -ás, -á, -emos, -éis, -ánを付けます。

- hablar → hablaré, hablarás, hablará, hablaremos, hablaréis, hablarán
- comer → comeré, comerás, comerá...
- vivir → viviré, vivirás, vivirá...

### 頻出の不規則動詞

| 不定詞 | 未来形（yo） |
|---|---|
| tener | tendré |
| hacer | haré |
| ir | iré |
| poder | podré |
| salir | saldré |
| venir | vendré |
| decir | diré |

### 例文

- Mañana iré al banco.（明日銀行に行きます）
- El año que viene viajaré a España.（来年スペインに旅行します）
- ¿Qué harás el fin de semana?（週末は何をしますか？）

**ミニ練習：**
1. Yo（tener）___ veinte años el mes que viene. → **tendré**
2. Yo（ir）___ al cine mañana. → **iré**
3. Yo（hacer）___ los deberes. → **haré**

## 3. 目的格代名詞：直接目的語（OD）と間接目的語（OI）

目的格代名詞は補語を置き換え、繰り返しを避けます。

### 直接目的語（OD）：lo, la, los, las

動作を直接受けるもの・人を置き換えます。

- 「Compré el libro」→「Lo compré.」（それを買った）
- 「Vi a María」→「La vi.」（彼女を見た）

### 間接目的語（OI）：le, les

動作の受け取り手（対象者）を置き換えます。

- 「Doy el regalo a María」→「Le doy el regalo.」（彼女にプレゼントをあげる）
- 「Doy el regalo a mis padres」→「Les doy el regalo.」（彼らにプレゼントをあげる）

### 代名詞の位置

- 活用された動詞と一緒の場合：動詞の前に置く。→「Lo compré.」
- 不定詞と一緒の場合：文末に結合する。→「Quiero comprarlo.」
- 現在分詞と一緒の場合：文末に結合する。→「Estoy comprándolo.」

> **よくある間違い：** 「lo」（OD）と「le」（OI）を混同すること。「Doy el regalo a María」→「Le doy el regalo」（OI）が正しく、「Lo doy」ではありません。

**ミニ練習：**
1. 「Compré el libro」→「___ compré」 → **Lo**
2. 「Doy el regalo a María」→「___ doy el regalo」 → **Le**
3. 「Quiero comprar el coche」→「Quiero comprar___」 → **lo**

## 4. 比較級と最上級

### 比較級

- **Más... que**（より〜）：Mi coche es más rápido que el tuyo.（私の車は君のより速い）
- **Menos... que**（より〜でない）：Este libro es menos caro que aquel.（この本はあれより安い）
- **Tan... como**（同じくらい〜）：Ella es tan alta como tú.（彼女は君と同じくらい背が高い）

### 最上級

「el/la/los/las + más + 形容詞」の形で作ります。

- Juan es el más alto de la clase.（フアンはクラスで一番背が高い）
- Esta casa es la más grande del barrio.（この家は近所で一番大きい）

### 頻出の不規則な形

| 形容詞 | 比較級 | 最上級 |
|---|---|---|
| bueno（良い） | mejor | el mejor |
| malo（悪い） | peor | el peor |
| grande（大きい・年上） | mayor | el mayor |
| pequeño（小さい・年下） | menor | el menor |

**ミニ練習：**
1. Mi coche es ___（más）grande que el tuyo. → **más**
2. Juan es el ___（mejor）de la clase. → **mejor**（buenoの不規則形）
3. Este examen es ___（peor）que el anterior. → **peor**（maloの不規則形）

## 5. 動詞の迂言的表現

迂言的表現は、活用された動詞＋接続語＋不定詞／現在分詞の組み合わせです。A2では次の3つが重要です。

### ir a + 不定詞（近接未来）

すぐに実行する予定を表します。

- Voy a estudiar esta noche.（今夜勉強するつもりです）
- ¿Vas a venir mañana?（明日来ますか？）

### tener que + 不定詞（義務）

必要性・義務を表します。

- Tengo que trabajar hoy.（今日は働かなければなりません）
- Tienes que hacer los deberes.（宿題をしなければなりません）

### poder + 不定詞（可能・許可）

能力や許可を表します。

- Puedes entrar.（入ってもいいですよ）
- No puedo salir hoy.（今日は出かけられません）

**ミニ練習：**
1. Tengo que ___（trabajar）hoy. → **trabajar**
2. Voy a ___（estudiar）esta noche. → **estudiar**
3. ¿Puedo ___（entrar）? → **entrar**
