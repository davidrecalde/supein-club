# スペイン語A1文法まとめ

A1レベルは、スペイン語の土台を築く段階です。このレベルの文法は、これから先すべての基礎になるものなので、最初にしっかり固めておくことが大切です。このページでは、[セルバンテス学院のカリキュラム大綱（PCIC）](https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/indice.htm)に基づくA1の文法項目——動詞*ser*と*estar*、名詞・形容詞の性と数、冠詞、直説法現在形、頻出不規則動詞、人称代名詞——をブロックごとに整理して解説します。

各ブロックには、分かりやすい説明・例文・解答付きのミニ練習問題がついています。A1レベル全体の見取り図が欲しい方は[A1ハブ](/language/learn-spanish/a1/)から、学習の順序を立てたい方は[A1学習計画](/language/learn-spanish/a1/study-plan/)からどうぞ。

## 1. ser と estar：A1最大の壁

日本人学習者にとって最初の大きな壁は、*ser*と*estar*の違いです。どちらも日本語では「〜である／〜にいる」に相当しますが、使われる文脈が異なります。

### serを使う場合
**アイデンティティ・出身・職業・本質的な特徴**を表すときに*ser*を使います。

- Soy japonés.（私は日本人です／出身）
- Soy estudiante.（私は学生です／職業）
- La casa es grande.（その家は大きい／本質的な特徴）
- El libro es rojo.（その本は赤い）

### estarを使う場合
**身体的・精神的な一時的状態や、場所**を表すときに*estar*を使います。

- Estoy cansado.（疲れている／状態）
- Estoy contento.（うれしい／気持ちの状態）
- Estoy en Tokio.（東京にいる／場所）
- La tienda está cerrada.（その店は閉まっている／状態）

### 覚え方のコツ
- *Ser* ＝「何であるか」「どこ出身か」「本来どのような性質か」。
- *Estar* ＝「今どんな状態か」「どこにいるか」。

> **日本人によくある間違い：** 「Soy japonés」の代わりに「Estoy japonés」と言ってしまうこと（出身は恒常的な性質なので*ser*を使います）。

**ミニ練習：** *ser*か*estar*か？
1. Yo ___ estudiante. → **soy**
2. María ___ en la escuela. → **está**
3. El coche ___ rojo. → **es**
4. Hoy ___ muy cansado. → **estoy**

## 2. 名詞・形容詞の性と数

スペイン語の名詞には**性**（男性・女性）と**数**（単数・複数）があります。これは日本語には存在しない概念なので、最初に気づく大きな違いのひとつです。

### 性の基本ルール
- **-o**で終わる名詞 → 男性名詞：el libro（本）、el perro（犬）
- **-a**で終わる名詞 → 女性名詞：la casa（家）、la mesa（机）
- 形容詞は名詞の性に一致します：libro rojo（赤い本）／ mesa roja（赤い机）

### 複数形
- 母音で終わる場合は**-s**をつける：libro → libros、casa → casas
- 子音で終わる場合は**-es**をつける：profesor → profesores

### よくある例外
- **el problema, el tema, el idioma, el sistema**（-maで終わるが男性名詞）
- **la mano, la foto, la moto**（-oで終わるが女性名詞）
- **-ión**で終わる単語は女性名詞であることが多い：la canción（歌）、la televisión（テレビ）

**ミニ練習：**
1. La casa ___（rojo/roja） → **roja**
2. Los libros ___（azul/azules） → **azules**
3. 「el problema」は男性名詞か女性名詞か → **男性名詞**

---

## 3. 定冠詞と不定冠詞

冠詞は名詞とセットで使われ、性と数に一致します。

| | 定冠詞 | 不定冠詞 |
|---|---|---|
| 男性単数 | el libro | un libro |
| 女性単数 | la casa | una casa |
| 男性複数 | los libros | unos libros |
| 女性複数 | las casas | unas casas |

### al への縮約
前置詞*a*が定冠詞*el*と結びつくと、**al**に縮約されます。

- Voy **a el** banco. → Voy **al** banco.（銀行に行きます）

**ミニ練習：**
1. ___ perro es grande（定冠詞） → **El**
2. Quiero ___ café（不定冠詞） → **un**
3. Voy a + el colegio → **al colegio**

## 4. 直説法現在形（規則動詞）

直説法現在形は、A1でもっともよく使われる時制です。規則動詞は語尾の**-ar、-er、-ir**によって活用が決まります。

### hablar（-ar型）
| 人称 | 活用形 |
|---|---|
| yo | hablo |
| tú | hablas |
| él/ella/usted | habla |
| nosotros/as | hablamos |
| vosotros/as | habláis |
| ellos/ellas/ustedes | hablan |

### comer（-er型）
| 人称 | 活用形 |
|---|---|
| yo | como |
| tú | comes |
| él/ella/usted | come |
| nosotros/as | comemos |
| vosotros/as | coméis |
| ellos/ellas/ustedes | comen |

### vivir（-ir型）
| 人称 | 活用形 |
|---|---|
| yo | vivo |
| tú | vives |
| él/ella/usted | vive |
| nosotros/as | vivimos |
| vosotros/as | vivís |
| ellos/ellas/ustedes | viven |

**ミニ練習：**
1. Yo ___（hablar）español. → **hablo**
2. Tú ___（comer）pan. → **comes**
3. Nosotros ___（vivir）en Tokio. → **vivimos**

## 6. 人称代名詞とtú/usted

スペイン語の人称代名詞は、誰がその動作をするかを示します。日本語と違い、スペイン語では**人称代名詞を省略することが多く**あります。動詞の活用形自体がすでに人称を示しているからです（*hablo*と言えば、主語が*yo*であることは自明です）。

| 代名詞 | 人称 |
|---|---|
| yo | 一人称単数 |
| tú | 二人称単数（非フォーマル） |
| él/ella/usted | 三人称単数（usted＝フォーマル） |
| nosotros/as | 一人称複数 |
| vosotros/as | 二人称複数（非フォーマル） |
| ellos/ellas/ustedes | 三人称複数 |

### tú と usted の違い
- **tú**は非フォーマル：友人、家族、同世代の人に対して使います。
- **usted**はフォーマル：初対面の人、目上の人、フォーマルな場面で使います。

> スペインでは*vosotros*が非フォーマルな複数形として使われますが、中南米ではすべての場合に*ustedes*が使われます。敬語という明確な丁寧さの体系を持つ日本語話者にとって、この*tú/usted*の対比は自然に理解しやすいポイントです。
