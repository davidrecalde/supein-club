# スペイン語発音入門（A1）

発音は、間違った発音のクセを積み重ねてしまう前に、スペイン語学習の最初に取り組むべき項目です。最初のうちに音を直すのは数分の手間ですが、何ヶ月も練習を重ねたあとに口のクセを直すのはずっと大変です。このページでは、[セルバンテス学院のカリキュラム大綱（インベントリー3）](https://cvc.cervantes.es/ensenanza/biblioteca_ele/plan_curricular/indice.htm)に基づくA1レベルの音声の基礎——5つの母音、アルファベット、日本語話者にとって最初に難しく感じる音——を紹介します。

これはあくまで入門編です。巻き舌のrとlの完全な練習、ミニマルペア、カメラを使った口の動きの確認などは、[日本人のためのスペイン語発音ガイド](/language/learn-spanish/pronunciation-for-japanese/)で詳しく扱っています。

---

## 1. スペイン語の5つの母音

スペイン語には**a, e, i, o, u**という5つの母音の音しかありません。日本語話者にとっての大きな強みは、この5つの母音が、単語の中のどこにあっても**常に同じ音**であることです。英語のように、*cat*・*car*・*cake*で「a」の音が変わってしまうようなことはありません。

| 母音 | 音（読み方の目安） | 例 |
|---|---|---|
| a | あ | casa, gato, sal |
| e | え | mesa, pez, leche |
| i | い | sí, rico, mi |
| o | お | ojo, sol, dos |
| u | う | mucho, tú, luz |

### 黄金ルール

それぞれの母音は、はっきりと分けて発音します。紛らわしい二重母音や、発音しない母音はありません。単語を見たら、そのまま一文字ずつ読めば大丈夫です。

### 音読練習

各母音をはっきり意識しながら、声に出して読んでみましょう。

- **ma-me-mi-mo-mu**
- **pa-pe-pi-po-pu**
- **la-le-li-lo-lu**

> **日本人によくある間違い：** 日本語の影響で母音を伸ばしたり短くしたりしてしまうこと（たとえば「お母さん」のように長母音になる）。スペイン語ではどの母音も同じ長さで発音します。

---

## 2. スペイン語のアルファベット

スペイン語のアルファベットは27文字です（日本語のローマ字にも英語にも存在しない**ñ**を含みます）。各文字の名称と例を見てみましょう。

| 文字 | 名称 | 例 |
|---|---|---|
| a | ア | agua |
| b | ベ | boca |
| c | セ | casa, cine |
| d | デ | dedo |
| e | エ | él |
| f | エフェ | flor |
| g | ヘ | gato, gente |
| h | アチェ | hola（無音） |
| i | イ | iglesia |
| j | ホタ | jamón |
| k | カ | kilo |
| l | エレ | luna |
| m | エメ | mesa |
| n | エネ | noche |
| ñ | エニェ | España, niño |
| o | オ | ojo |
| p | ペ | perro |
| q | ク | queso |
| r | エレ（巻き舌） | ratón |
| s | エセ | sol |
| t | テ | taza |
| u | ウ | uva |
| v | ウベ | vino |
| w | ウベ・ドブレ | whisky |
| x | エキス | México |
| y | イェ／イ・グリエガ | yo, ley |
| z | セタ | zapato |

### 日本人が押さえておきたいポイント

- **h**は無音です。「hola」は「オラ」と読み、「ホラ」とは読みません。
- **ñ**は鼻に抜ける音です（日本語の「にょ」に近い音）：España, niño, año。
- **ll**（多くのスペイン語圏で「イェイスモ」と呼ばれる現象）は「y」のような音になります：calle, llama。
- **c**と**z**は、スペイン本土のスペイン語では英語のthinkの「th」に近い/θ/の音になりますが、中南米ではどちらも/s/の音になります（この現象を「セセオ」と呼びます）。

> 日本語のローマ字とは違い、スペイン語の「v」と「b」は非常に似た音になります（英語のように下唇を噛んで発音する「v」ではありません）。

## 3. rとlの入門

日本語話者にとって、これはおそらくスペイン語発音でもっとも大きな壁です。スペイン語には、日本語では混同されがちな「r/l」の3つの音があります。

### 3つの音

1. **l（エレ）/l/**：側面音の子音で、日本語の「ら行」に近い音。例：*lo, la, luna, pelo*。
2. **単一のr（erre simple）/ɾ/**（単一のはじき音）：舌を一瞬だけ弾く短い音。**母音と母音の間**に現れます：*pero, caro, cero, ara, ere, oro*。
3. **二重のr（erre doble）/r/**（巻き舌の震え音）：舌が複数回震える音。**「rr」**、または**語頭・音節頭の「r」**として現れます：*perro, carro, rojo, ratón, rosa*。

### 重要な注意点

音節や単語の**語頭**にある「r」（ra, re, ri, ro, ru；ratón, rojo）は、**巻き舌の二重r /r/** として発音されます。単一のrではありません。単一のr /ɾ/ が現れるのは、**単語の中で母音に挟まれているとき**だけです。

### ミニマルペア

次の単語のペアは、rの種類だけで意味が変わります。聞いて、繰り返してみましょう。

| 単一のr /ɾ/ | 二重のr /r/ | 意味 |
|---|---|---|
| pero | perro | pero（しかし）／perro（犬） |
| caro | carro | caro（高い）／carro（車） |
| cero | cerro | cero（ゼロ）／cerro（丘） |
| oro | — | oro（金） |

l（エレ）/l/ も合わせると：

| l /l/ | 単一のr /ɾ/ | 二重のr /r/ |
|---|---|---|
| pelo | pero | perro |
| calo | caro | carro |
| celo | cero | cerro |

> **日本人の方へ：** 日本語にはこの区別が存在しないため、最初は難しく感じます。あきらめないでください。毎日5分の練習で必ず身につきます。

### 練習

1. 声に出して言ってみましょう：pero – perro – pero – perro
2. 言ってみましょう：caro – carro – calo
3. 言ってみましょう：cero – cerro – celo

口の動きをカメラで確認できる完全な練習は、[日本人のための発音ガイド](/language/learn-spanish/pronunciation-for-japanese/)にあります。

## 4. A1の実践練習

### 音読

次の文を、母音とr/lに気をつけながら声に出して読んでみましょう。

- Hola, soy japonés.（こんにちは、私は日本人です）
- Buenos días, profesor.（おはようございます、先生）
- Mi perro es grande y caro.（私の犬は大きくて、（値段が）高いです）
- Tengo veinte años.（私は20歳です）
- ¿Qué hora es? Son las tres.（何時ですか？3時です）

### ペアの反復練習

それぞれのペアを3回ずつ、舌の使い方の違いを意識しながら繰り返しましょう。

- pero / perro
- caro / carro
- pelo / perro

> 発音を文法と組み合わせて練習したい方は、[A1文法](/language/learn-spanish/a1/grammar/)で動詞serや現在形を使ったモデル文を確認できます。
