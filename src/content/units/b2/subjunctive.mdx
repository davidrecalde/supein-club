接続法過去は、過去の文の中や、現実とは違うことを願うときに使う接続法の形です。点過去の ellos の形（hablaron, tuvieron）から -ron を取り、-ra または -se の語尾をつけて作ります。

[ユニット25](/language/learn-spanish/b1/subjunctive/)で学んだ接続法現在は、今やこれからのことへの願いや気持ちを表す形でした。B2 では、「〜してくれたらよかったのに」「もし〜だったら」のように、過去のことや現実と違うことも表せるようになります。その土台になるのが接続法過去です。作り方は点過去がわかっていれば難しくありませんが、点過去の不規則な形をそのまま使うので、点過去の復習にもなります。このユニットでは、サラマンカでの留学生活も2年目に入ったユイが、夕暮れの部屋で日記を書きながら、東京のダニエルと話す場面を例に、接続法過去の形を身につけます。

## 文法：接続法過去の活用 (Gramática)

まず規則動詞の作り方を、次に -ra 形と -se 形の関係を、最後に不規則な形と主な使い方を見ていきましょう。

### 作り方：点過去の ellos の形から

接続法過去は、直説法の点過去から作ります。

1. 点過去の ellos の形を思い出す（hablaron, comieron, vivieron）。
2. 語尾の -ron を取る（habla-, comie-, vivie-）。
3. -ra, -ras, -ra, -ramos, -rais, -ran をつける。

| | hablar（話す） | comer（食べる） | vivir（住む） |
| --- | --- | --- | --- |
| yo | hablara | comiera | viviera |
| tú | hablaras | comieras | vivieras |
| él / ella / usted | hablara | comiera | viviera |
| nosotros | habláramos | comiéramos | viviéramos |
| vosotros | hablarais | comierais | vivierais |
| ellos / ellas / ustedes | hablaran | comieran | vivieran |

すべての動詞が、例外なくこの作り方に従います。-ar 動詞は -ara、-er・-ir 動詞は -iera という形になります。

### -ra 形と -se 形

接続法過去には、-ra で終わる形と -se で終わる形の二つがあり、ほとんどの場合、同じ意味で使えます。-se 形は、-ra を -se に替えて作ります。

| -ra 形 | -se 形 |
| --- | --- |
| hablara, hablaras, hablara | hablase, hablases, hablase |
| habláramos, hablarais, hablaran | hablásemos, hablaseis, hablasen |
| tuviera, tuvieras, tuviera | tuviese, tuvieses, tuviese |

話し言葉では -ra 形のほうがよく使われ、-se 形は書き言葉や、スペインの一部の地域でよく見られます。まずは -ra 形で話せるようにし、-se 形は読んで意味がわかれば十分です。ただし、quisiera（〜したいのですが）のような丁寧な言い方は、-ra 形だけで使います。

### 不規則な形：点過去の不規則がそのまま

点過去の ellos の形が不規則な動詞は、その不規則な形から作ります。不定詞から作らないように気をつけましょう。

| 動詞 | 点過去（ellos） | 接続法過去 |
| --- | --- | --- |
| tener（持つ） | tuvieron | tuviera |
| estar（いる） | estuvieron | estuviera |
| poder（できる） | pudieron | pudiera |
| poner（置く） | pusieron | pusiera |
| saber（知っている） | supieron | supiera |
| querer（欲しい） | quisieron | quisiera |
| venir（来る） | vinieron | viniera |
| hacer（する） | hicieron | hiciera |
| decir（言う） | dijeron | dijera |
| ser / ir | fueron | fuera |
| dar（与える） | dieron | diera |
| leer（読む） | leyeron | leyera |
| pedir（頼む） | pidieron | pidiera |
| dormir（眠る） | durmieron | durmiera |

ser と ir は、点過去と同じく接続法過去も fuera で同じ形です。どちらの意味かは文脈で判断します。haber の hubiera は、完了形を作るときに使います（→ ユニット39）。

### どんなときに使う？

接続法過去を使う主な場面は、次のとおりです。くわしい使い方は、このあとのユニットで一つずつ学びます。

- **過去の文の中で（時制の一致）**：Quiero que vengas.（来てほしい）→ Quería que vinieras.（来てほしかった）→ ユニット40
- **現実と違う仮定**：Si tuviera tiempo, viajaría más.（時間があれば、もっと旅行するのに）→ ユニット38
- **実現しそうにない願い**：Ojalá tuviera más tiempo.（もっと時間があればいいのに）。実現しうる願いは Ojalá tenga tiempo.（時間があるといいな）と接続法現在で言います。
- **丁寧な希望**：Quisiera un café con leche, por favor.（カフェ・コン・レチェをいただきたいのですが）

### ダニエルとのビデオ通話

日記を書き終えたユイが、東京のダニエルとビデオ通話をします。

- Daniel: ¿Qué tal en Salamanca, Yui?（サラマンカはどう、ユイ？）
- Yui: Muy bien, pero a veces echo de menos Japón. Ojalá mi familia viviera más cerca.（いいよ。でも、ときどき日本が恋しくなるの。家族がもっと近くに住んでいたらいいのに）
- Daniel: Te entiendo. Mi madre siempre me decía que estudiara idiomas, y aquí estoy, en Tokio.（わかるよ。母はいつも、語学を勉強しなさいって言っていたんだ。それで今は東京にいるってわけ）
- Yui: ¡Qué bien! Yo quisiera quedarme un año más.（いいね！私はもう1年いられたらいいな）

**ダニエル（バレンシア出身）のひとこと：** スペインでは、-ra 形と -se 形の両方を耳にします。Si tuviera tiempo… と Si tuviese tiempo… は同じ意味で、-se 形のほうが少し改まって聞こえることがあります。ただ、お店で Quisiese un café. とは言いません。丁寧に頼むときの quisiera だけは、いつも -ra 形です。

## 活用：今日の動詞 (Conjugación)

今日の動詞は、点過去が不規則な [tener](/language/learn-spanish/verb-conjugation/tener/)、[hacer](/language/learn-spanish/verb-conjugation/hacer/)、[estar](/language/learn-spanish/verb-conjugation/estar/)、[poder](/language/learn-spanish/verb-conjugation/poder/)、[decir](/language/learn-spanish/verb-conjugation/decir/) と、fuera の形を共有する [ser](/language/learn-spanish/verb-conjugation/ser/) と [ir](/language/learn-spanish/verb-conjugation/ir/) です。活用表のページでは、点過去と接続法過去（-ra 形・-se 形）を並べて確認できます。点過去の ellos の形を言ってから、接続法過去を作る練習をしましょう。

## 語彙 (Nociones específicas)

留学生活をふり返るときの言葉と、aconsejar（助言する）や sugerir（提案する）のように、過去の文で接続法過去を続ける動詞です：Me aconsejó que estudiara idiomas.（語学を勉強するよう助言してくれた）。

## 発音・正書法 (Pronunciación y ortografía)

接続法過去の nosotros の形は、後ろから3番目の音節を強く読むので、いつもアクセント記号がつきます：habláramos、tuviéramos、fuéramos、hablásemos。また、アクセント記号の有無で意味が変わる形に注意しましょう。hablara（接続法過去）は後ろから2番目を、hablará（未来）は最後を強く読みます：Ojalá hablara español.（スペイン語が話せたらいいのに）／Mañana hablará con el profesor.（明日、先生と話すだろう）。

## 日本人がよく間違える

接続法過去でつまずくのは、次の四つです。

- **不定詞から作る。** ×teniera、×hacieran、×dormieran → ○**tuviera**、○**hicieran**、○**durmieran**。必ず点過去の ellos の形から作ります。
- **nosotros のアクセント記号を忘れる。** ×hablaramos、×fueramos → ○habl**á**ramos、○fu**é**ramos。
- **過去の文で接続法現在を使う。** ×Me pidió que venga. → ○Me pidió que **viniera**.（来るよう私に頼んだ）。主節が過去なら、que のあとはふつう接続法過去です（→ ユニット40）。
- **hablara と hablará を混同する。** アクセント記号一つで、接続法過去と未来が入れかわります。

## 文化メモ (Referentes culturales)

<CultureNote>

スペインの新聞やニュースでは、el que fuera presidente del Gobierno のような言い方をよく見かけます。この fuera は願いや仮定ではなく、「かつて首相だった人」という意味です。接続法過去の -ra 形は、もとはラテン語の直説法の過去完了（「〜していた」）から生まれた形で、その古い意味が、報道や文学の関係節の中に今も残っています。話し言葉ではほとんど使いませんが、スペインの新聞記事を読むときに知っておくと戸惑いません。

</CultureNote>

## まとめ

- 接続法過去は、点過去の ellos の形から -ron を取り、-ra（または -se）の語尾をつけて作る。nosotros の形には、いつもアクセント記号がつく。
- 点過去が不規則な動詞は、その形から作る：tuvieron → tuviera、fueron → fuera、hicieron → hiciera。
- 過去の文の中、現実と違う仮定、実現しそうにない願い（ojalá）、丁寧な希望（quisiera）で使う。

次のユニット38では、si + 接続法過去で「もし〜なら」と現実と違う仮定を表す条件文を学びます。
