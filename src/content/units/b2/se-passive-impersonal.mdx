スペイン語の se には、「だれがするか」を言わずに説明する二つの使い方があります。一つは再帰受動で、Se venden pisos.（マンション売ります）のように、動詞を物の数に合わせます。もう一つは無人称の se で、En España se cena tarde.（スペインでは夕食が遅い）、Se busca a dos camareros.（ウェイター2名募集）のように、動詞はいつも3人称単数です。

ユニット32で se の受け身の基本を学びました。このユニットでは、二つの違いと見分け方、そしてレシピや張り紙、一般論で使う言い方を、アルバイトを探すユイと、料理を教えるダニエルの例で学びます。

## 文法：再帰受動と無人称の se (Gramática)

まず二つの se の違いを、次に人が目的語のときの形を、最後に se 以外の無人称表現を見ていきましょう。

### 再帰受動：動詞を物の数に合わせる

se + 他動詞 + 物（主語）の形で、物が「〜される」ことを表します。動詞は物の数に合わせます。

| 物 | 形 | 例 |
| --- | --- | --- |
| 単数 | se + 3人称単数 | Se alquila habitación.（部屋貸します） |
| 複数 | se + 3人称複数 | Se venden pisos.（マンション売ります） |

物の名詞は動詞の後ろに置くのがふつうです。前に置くときは、Las entradas se venden en la taquilla.（チケットは窓口で売っています）のように、冠詞をつけて特定の物について話す言い方になります。

### 無人称の se：いつも3人称単数

目的語がないとき、人が目的語（a + 人）のとき、後ろが動詞の原形のときは、動詞はいつも3人称単数です。

二つの se は、se の後ろの名詞が動詞の主語になれるかどうかで見分けます。Se venden pisos. の pisos は主語なので、動詞を数に合わせます。Se busca a dos camareros. の a dos camareros は前置詞 a がついているので主語になれず、動詞は単数のままです。

<Examples>

- En España se cena tarde.（スペインでは夕食が遅い）
- Se busca a dos camareros.（ウェイター2名募集）
- Aquí no se puede fumar.（ここではたばこが吸えない）

</Examples>

### 人が目的語のとき：a の有無で変わる

| 人の扱い | 形 | 例 |
| --- | --- | --- |
| a + 人 | 無人称：単数 | Se busca a dos camareros con experiencia. |
| a のない人（不特定の人をまとめて言う） | 再帰受動：数を合わせる | Se necesitan voluntarios. |

人に a をつけるかどうかは、だれを指すかがはっきりしているかで決まることが多く、求人の張り紙ではどちらの形も見かけます。a があれば動詞は単数、と覚えておきましょう。

### 張り紙の決まった表現

| 表現 | 意味 | 動詞の形 |
| --- | --- | --- |
| Se prohíbe fumar. | 禁煙 | 単数（後ろが原形） |
| Se ruega silencio. | お静かに願います | 単数（silencio に合わせる） |
| Se aceptan tarjetas. | カード使えます | 複数（tarjetas に合わせる） |
| Aquí se habla inglés. | 英語が通じます | 単数（目的語なし） |

駅や美術館、店の入り口などで見かける短い文です。どれも「だれが」を言わずに、規則や情報を伝えています。

### se 以外の無人称表現

| 表現 | 例 | 意味 |
| --- | --- | --- |
| 3人称複数 | Dicen que va a llover. | 雨が降るそうだ |
| uno + 3人称単数 | Uno nunca sabe lo que puede pasar. | 何が起こるかわからないものだ |
| tú（一般の「あなた」） | Si estudias, aprendes. | 勉強すれば身につく |

再帰動詞（acostumbrarse など）を無人称にするときは、se を二つ重ねられないので uno を使います：Uno se acostumbra a todo.（人は何にでも慣れるものだ）。

三つは、se がいちばん客観的で書き言葉にも向き、uno は話し手自身の実感を込めた言い方、tú は会話で相手を巻き込むくだけた言い方です。作文では se を中心に使いましょう。

### アルバイト探し

- Yui: Mira, en esta cafetería se busca a una camarera. Y en la tienda de al lado se necesitan dependientes.（見て、このカフェでウェイトレスを募集してる。隣の店でも店員が必要だって）
- Daniel: ¿Y qué se pide?（何が求められてるの？）
- Yui: Se valora hablar inglés y se requiere experiencia. Bueno, dicen que en verano se contrata a mucha gente.（英語が話せると評価されて、経験が必要だって。まあ、夏はたくさん雇うらしいけど）

ユイの文には、se busca a una camarera（a + 人：単数）、se necesitan dependientes（a のない人：複数）、se valora hablar inglés（後ろが原形：単数）と、三つの形がそろっています。dicen que は、3人称複数の無人称表現です。

**ダニエル（バレンシア出身）のひとこと：** 日本語の「〜されている」「〜と言われている」は、スペイン語では ser の受動態（ユニット32）より、se を使う方がずっと自然なことが多いです。Aquí se habla inglés. や Se dice que… は、看板や会話の定番です。

## 活用：今日の動詞 (Conjugación)

se の文で使う動詞は、ほとんどが3人称の単数か複数です。freír（揚げる）は fríe / fríen と i にアクセント記号がつき、過去分詞は frito（freído も可）です。[hacer](/language/learn-spanish/verb-conjugation/hacer/)（se hace）、[poder](/language/learn-spanish/verb-conjugation/poder/)（se puede）の現在形と点過去を、活用表で確認しておきましょう。

## 発音・正書法 (Pronunciación y ortografía)

張り紙や看板の文は短く、冠詞が省かれることがよくあります：Se alquila habitación.（Se alquila una habitación. とも言えますが、張り紙では冠詞を省くのがふつうです）、Se vende piso. 読むときは、se を弱く、後ろの動詞を強く読みます：se **ven**de、se al**qui**la。

## 日本人がよく間違える

- **再帰受動で動詞の数を合わせない。** ×Se vende pisos. → ○Se **venden** pisos.
- **a + 人のときに動詞を複数にする。** ×Se buscan a dos camareros. → ○Se **busca** a dos camareros.
- **後ろが原形なのに動詞を複数にする。** ×Aquí no se pueden fumar. → ○Aquí no se **puede** fumar.

## 文化メモ (Referentes culturales)

<CultureNote>

スペイン語のレシピは、se の文の宝庫です。トルティージャ・エスパニョーラなら、Se pelan las patatas, se cortan en rodajas y se fríen. Luego se baten los huevos y se mezcla todo.（じゃがいもの皮をむき、薄切りにして揚げる。それから卵を溶き、全部を混ぜる）。最後の論点は、玉ねぎを入れるかどうかです。¿Se pone cebolla o no se pone?（玉ねぎは入れる？入れない？）は、スペイン人の間でも意見が分かれます。タパスの定番料理は、[タパス文化完全ガイド](/food/tapas/)で紹介しています。

</CultureNote>

## 練習 (Procedimientos de aprendizaje)

### 練習1：単数？ 複数？

正しい方を選んでください。

1. Se (vende / venden) coches usados.
2. Se (alquila / alquilan) habitación.
3. Se (busca / buscan) a una profesora de inglés.
4. En verano se (come / comen) mucho gazpacho.
5. Aquí no se (puede / pueden) aparcar.

<details>
<summary>答えを見る</summary>

1. venden（coches は複数）
2. alquila（habitación は単数）
3. busca（a + 人）
4. come（gazpacho は単数）
5. puede（後ろが原形）

</details>

### 練習2：se を使って書きかえる

次の文を、se を使って書きかえてください。

1. La gente cena tarde en España.
2. Venden entradas en la taquilla.
3. Buscamos a un camarero.
4. Hablan inglés en esta tienda.

<details>
<summary>答えを見る</summary>

1. En España se cena tarde.
2. Se venden entradas en la taquilla.
3. Se busca a un camarero.
4. En esta tienda se habla inglés.

</details>

## まとめ
