スペイン語の名詞は、人だけでなく物にもすべて男性・女性の区別があり、その性と数（単数・複数）に合わせて冠詞の形が変わります。多くは -o で終わると男性名詞（el libro）、-a で終わると女性名詞（la maleta）ですが、例外もあるので、名詞は冠詞といっしょに覚えるのが近道です。

日本語には冠詞がないので、最初は面倒に感じるかもしれません。でも、el と la、un と una の区別は、スペイン語のあらゆる文に出てきます。このユニットでは、初めてのスペイン旅行でマドリードに着いたミナといっしょに、空港やホテル、バルで出会う物の名前を覚えていきます。

## 文法：名詞の性・数と冠詞 (Gramática)

まず名詞の性の見分け方を、次に複数形の作り方を、最後に冠詞の使い分けを見ていきましょう。

### 名詞の性：男性名詞と女性名詞

語尾を見ると、多くの名詞の性がわかります。

| 語尾 | 性 | 例 |
| --- | --- | --- |
| -o | 男性 | el museo（美術館）、el libro（本） |
| -a | 女性 | la maleta（スーツケース）、la tarjeta（カード） |
| -ción, -sión | 女性 | la estación（駅）、la televisión（テレビ） |
| -dad, -tad, -tud | 女性 | la ciudad（都市）、la libertad（自由） |
| -aje, -or | 男性（ほとんど） | el viaje（旅行）、el color（色） |
| -e、子音 | 決まりなし | el hotel（ホテル）、la calle（通り）、el billete（切符）、la llave（鍵） |

-e や子音で終わる名詞は、語尾から性がわかりません。新しい名詞は、必ず el / la をつけて覚えましょう。

**よく使う例外**もあります。

- -a でも男性：el día（日）、el mapa（地図）、el problema（問題）、el idioma（言語）
- -o でも女性：la mano（手）、la foto（写真）、la moto（バイク）。foto と moto は fotografía、motocicleta の短縮形です。

人を表す名詞は、多くが男女で形を変えます：el chico / la chica（男の子／女の子）、el profesor / la profesora（先生）。el estudiante / la estudiante（学生）のように、冠詞だけで性を示す名詞もあります。

### 数：複数形の作り方

| 単数の語尾 | 複数の作り方 | 例 |
| --- | --- | --- |
| 母音 | -s | el libro → los libros、la calle → las calles |
| 子音 | -es | el hotel → los hoteles、la ciudad → las ciudades |
| -z | z → c + -es | el lápiz → los lápices |
| 強く読まない母音 + s | 変わらない | el lunes → los lunes |

<Examples>

- Dos billetes, por favor.（切符を2枚ください）
- Mina tiene dos maletas.（ミナはスーツケースを2つ持っている）

</Examples>

### 冠詞：定冠詞と不定冠詞

| | 男性・単数 | 女性・単数 | 男性・複数 | 女性・複数 |
| --- | --- | --- | --- | --- |
| 定冠詞（その〜） | el | la | los | las |
| 不定冠詞（ある〜・一つの〜） | un | una | unos | unas |

使い分けの基本は、日本語の「が」と「は」に少し似ています。

- **un / una**：初めて話題にする物、数えて「一つの」と言う物。
- **el / la**：話し手と聞き手の両方がどれのことかわかっている物、一つしかない物。

<Examples>

- Mina tiene una maleta. La maleta es azul.（ミナはスーツケースを持っている。そのスーツケースは青い）
- Un café con leche, por favor.（カフェ・コン・レチェを一つください）
- La cuenta, por favor.（お会計をお願いします）

</Examples>

**a + el と de + el** は、必ず一語にまとめます：Voy al museo.（美術館に行く）、la llave del hotel（ホテルの鍵）。la、los、las はまとめません（a la estación）。

**el agua**：強く読む a で始まる女性名詞は、単数のときだけ el をつけます（el agua fría、冷たい水）。複数は las aguas です。

**ダニエル（バレンシア出身）のひとこと：** 同じ物でも、スペインと中南米で単語が違うことがあります。携帯電話はスペインでは el móvil、中南米では el celular。ジュースは el zumo と el jugo です。パソコンはスペインでは el ordenador（男性）、中南米では la computadora（女性）で、単語が変わると性も変わります。単語ごとに冠詞をつけて覚えておけば安心です。

## 発音・正書法 (Pronunciación y ortografía)

複数形にすると、アクセント記号が消えたり、ついたりすることがあります。強く読む音節の位置は単数でも複数でも同じですが、語が長くなるとアクセント記号の決まりが変わるためです。la estación（エス・タ・**シオン**）→ las estaciones（エス・タ・**シオ**・ネス）では記号が消え、el joven（**ホ**・ベン）→ los jóvenes（**ホ**・ベ・ネス）では記号がつきます。

## 日本人がよく間違える

日本語には冠詞も名詞の性もないので、次の三つでつまずく人がとても多いです。

- **冠詞を落とす。** ×Necesito billete. → ○Necesito **un** billete.（切符が1枚必要です）。数えられる名詞を単数で使うときは、ほぼ必ず冠詞がつきます。
- **語尾だけで性を決める。** ×la mapa、×el mano、×el ciudad → ○**el** mapa、○**la** mano、○**la** ciudad。-a / -o の例外と、-dad、-ción などの女性名詞に注意しましょう。
- **英語のように -s だけで複数にする。** ×hotels、×lápizs → ○hotel**es**、○lápi**ces**。子音で終わる名詞は -es です。

## 文化メモ (Referentes culturales)

<CultureNote>

スペインのバルでは、短い注文の中に冠詞がよく登場します。Un café con leche, por favor.（カフェ・コン・レチェを一つ）、Un zumo de naranja, por favor.（オレンジジュースを一つ）と頼むときは un、食べ終わって La cuenta, por favor.（お会計をお願いします）と言うときは la です。お会計はそのテーブルのものだと、店の人もわかっているからです。バルでの注文の流れやマナーは、[バル・レストラン活用ガイド](/food/spain-bar-restaurant/)で紹介しています。

</CultureNote>

## 練習 (Procedimientos de aprendizaje)

### 練習1：el か la か？

次の名詞につく定冠詞を答えてください。

1. ___ día
2. ___ ciudad
3. ___ mapa
4. ___ estación
5. ___ mano
6. ___ hotel

<details>
<summary>答えを見る</summary>

1. el día（-a でも男性）
2. la ciudad（-dad は女性）
3. el mapa（-a でも男性）
4. la estación（-ción は女性）
5. la mano（-o でも女性）
6. el hotel（子音で終わる名詞は、冠詞といっしょに覚える）

</details>

### 練習2：複数形と冠詞

1〜5 は冠詞ごと複数形にしてください。6 には un / una / el / la のどれかを入れてください。

1. el hotel
2. la calle
3. la estación
4. el lápiz
5. el lunes
6. Mina tiene ___ maleta. ___ maleta es azul.

<details>
<summary>答えを見る</summary>

1. los hoteles
2. las calles
3. las estaciones（アクセント記号が消える）
4. los lápices
5. los lunes（形は変わらない）
6. una / La（初めて話題にするときは una、その後は la）

</details>

### 練習3：作文

ミナになったつもりで、スペイン語で言ってみましょう。

1. 切符を2枚ください。
2. カフェ・コン・レチェとオレンジジュースを一つずつください。
3. ホテルの鍵をください。

<details>
<summary>解答例を見る</summary>

1. Dos billetes, por favor.
2. Un café con leche y un zumo de naranja, por favor.
3. La llave del hotel, por favor.

</details>

## まとめ

- スペイン語の名詞は、すべて男性か女性。-o は男性、-a は女性が多いが、el día や la mano などの例外もある。
- 複数形は、母音で終われば -s、子音で終われば -es。
- un / una は初めて話題にする物、el / la はどれのことかわかっている物。a + el は al、de + el は del。
