スペイン語で時刻を言うときは、ser を使って ¿Qué hora es?（何時ですか）とたずね、Es la una.（1時です）、Son las dos.（2時です）と答えます。1時だけが単数の es la una で、2時からは son las… になるのが特徴です。

このユニットでは、時刻のほかに、0から1000までの数字、曜日・月・日付、そして qué・dónde・cuánto などの疑問詞をまとめて学びます。マドリードの駅で、トレド行きの電車の切符を買うミナといっしょに、値段や時間をたずねる表現を身につけましょう。

## 文法：疑問詞・数・時刻・日付 (Gramática)

まず疑問詞を、次に数字と値段の言い方を、最後に時刻と日付を見ていきましょう。

### 疑問詞

| 疑問詞 | 意味 | 例 |
| --- | --- | --- |
| qué | 何・どんな | ¿Qué es esto?（これは何？） |
| quién / quiénes | だれ | ¿Quién es?（だれですか？） |
| dónde | どこ | ¿Dónde está el andén?（ホームはどこ？） |
| cuándo | いつ | ¿Cuándo es tu cumpleaños?（誕生日はいつ？） |
| cómo | どう・どのように | ¿Cómo estás?（元気？） |
| cuánto / cuánta / cuántos / cuántas | いくら・いくつ | ¿Cuántas entradas quieres?（入場券は何枚？） |
| cuál / cuáles | どれ | ¿Cuál es tu tren?（あなたの電車はどれ？） |
| por qué | なぜ | ¿Por qué estás aquí?（どうしてここに？） |

疑問詞には、必ずアクセント記号がつきます。cuánto は、後ろの名詞の性と数に合わせて形が変わります（¿Cuántos años tienes?、何歳？）。「なぜ」の por qué に答えるときは、1語でアクセント記号のない porque（〜だから）を使います。

**qué と cuál** は、どちらも「何」と訳せるので迷いやすい疑問詞です。ser の前で、いくつかの中から一つを答えてほしいときは cuál を使います：¿Cuál es tu número de teléfono?（あなたの電話番号は？）、¿Cuál es tu nombre?（お名前は？）。日本語につられて ¿Qué es tu número? と言うと、「番号とは何か」をたずねる不自然な文になります。名詞の前では qué を使います：¿Qué tren tomas?（どの電車に乗るの？）。

年齢は、ユニット5で学んだ tener を使ってたずねます：¿Cuántos años tienes? ── Tengo veintiocho años.（何歳？ ── 28歳です）。

### 数字

| 数 | 言い方 | 数 | 言い方 |
| --- | --- | --- | --- |
| 0〜5 | cero, uno, dos, tres, cuatro, cinco | 30 | treinta |
| 6〜10 | seis, siete, ocho, nueve, diez | 31 | treinta y uno |
| 11〜15 | once, doce, trece, catorce, quince | 40〜90 | cuarenta, cincuenta, sesenta, setenta, ochenta, noventa |
| 16〜19 | dieciséis, diecisiete, dieciocho, diecinueve | 100 | cien |
| 20〜22 | veinte, veintiuno, veintidós | 101 | ciento uno |
| 23〜29 | veintitrés, veinticuatro… veintinueve | 200 / 500 / 1000 | doscientos / quinientos / mil |

覚えるポイントは三つです。

1. **29までは1語、31からは y でつなぐ。** veintidós（22）、treinta y dos（32）。
2. **ちょうど 100 は cien、101 からは ciento。** 200〜900 は、名詞の性に合わせます（doscientas personas、200人）。500（quinientos）、700（setecientos）、900（novecientos）は形が不規則です。
3. **uno は名詞の前で un / una になる。** un euro、una entrada、veintiún euros。

### 値段をたずねる

¿Cuánto cuesta…?（いくらですか）とたずね、Cuesta doce euros.（12ユーロです）と答えます。複数の物なら ¿Cuánto cuestan? / Cuestan… です。2,50 € は dos euros con cincuenta（céntimos）、または短く dos cincuenta と読みます。

### 時刻

| 時刻 | 言い方 |
| --- | --- |
| 1:00 | Es la una. |
| 2:00 | Son las dos. |
| 2:15 | Son las dos y cuarto. |
| 2:30 | Son las dos y media. |
| 2:45 | Son las tres menos cuarto. |
| 2:50 | Son las tres menos diez. |

「〜時に」は a la una、a las dos のように a を使います：¿A qué hora sale el tren?（電車は何時に出ますか？）。午前・午後は de la mañana（朝の）、de la tarde（午後の）、de la noche（夜の）で区別します。駅の時刻表など公式の場面では、24時間制もよく使います（a las dieciocho treinta、18時30分）。

### 曜日・月・日付

- **曜日：** lunes, martes, miércoles, jueves, viernes, sábado, domingo（すべて男性名詞）。el lunes は「（今度の）月曜日に」、los lunes は「毎週月曜日に」です。
- **月：** enero, febrero, marzo, abril, mayo, junio, julio, agosto, septiembre, octubre, noviembre, diciembre。
- **日付：** el + 日 + de + 月 の順です：Hoy es lunes, dos de noviembre.（今日は11月2日、月曜日）。年は数字で読みます：2026 = dos mil veintiséis。

曜日も月も、スペイン語では小文字で書きます。

### 駅で切符を買う

駅の窓口で、ミナがトレド行きの切符を買います（時刻と値段は例です）。

- Mina: Buenos días. ¿A qué hora sale el próximo tren a Toledo?（おはようございます。トレド行きの次の電車は何時に出ますか？）
- Empleado: A las diez y cuarto.（10時15分です）
- Mina: ¿Cuánto cuesta el billete?（切符はいくらですか？）
- Empleado: Doce euros con cincuenta.（12ユーロ50セントです）
- Mina: ¿Y de qué andén sale?（何番ホームから出ますか？）
- Empleado: Del andén tres.（3番ホームです）

**ダニエル（バレンシア出身）のひとこと：** 月の1日は、スペインではふつう el uno de enero（1月1日）と言います。中南米では el primero de enero（「最初の日」）もよく使います。どちらも通じますが、スペインで日付を言うなら uno で大丈夫です。

## 活用：今日の動詞 (Conjugación)

このユニットで大事なのは、時刻を言う [ser](/language/learn-spanish/verb-conjugation/ser/) の es と son の使い分けです（Es la una. / Son las dos.）。値段をたずねる costar（cuesta / cuestan）は、ユニット5で学んだ o → ue の動詞です。年齢を言う tener（Tengo veintiocho años.）は [tener](/language/learn-spanish/verb-conjugation/tener/) のページで確認できます。

## 発音・正書法 (Pronunciación y ortografía)

スペインの大部分では、ce・ci と z を、英語の think の th のように、舌先を軽く歯ではさんで発音します。cinco（**シン**・コ）、doce（**ド**・セ）、cien（**シエン**）、zumo（**ス**・モ）の「シ」「セ」「ス」の部分です。中南米や、アンダルシアの一部・カナリア諸島では、この音を s で発音しますが、このコースはスペインの発音を基準にしています。

## 日本人がよく間違える

- **疑問詞のアクセント記号と ¿ を落とす。** ×Donde esta el anden? → ○**¿Dónde** está el andén? 疑問詞にはアクセント記号がつき、文頭には ¿ が必要です。
- **名詞の前で uno のまま使う。** ×veintiuno euros、×uno billete → ○**veintiún** euros、○**un** billete。
- **時刻の es と son を取り違える。** ×Es las dos. ×Son la una. → ○**Son las** dos. ○**Es la** una. 1時だけが単数です。

## 文化メモ (Referentes culturales)

<CultureNote>

スペインでは、値段の小数点にコンマを使い、ユーロ記号を数字の後ろに書きます。カフェのメニューに 2,50 € とあれば、2ユーロ50セントのことです。読むときは dos euros con cincuenta、お店ではさらに短く dos cincuenta と言うことも多いので、耳を慣らしておくと会計がスムーズです。旅の予算や物価の目安は、[スペイン旅行の費用ガイド](/travel/travel-cost/)で紹介しています。

</CultureNote>
