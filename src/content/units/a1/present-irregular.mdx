スペイン語の現在形には、規則どおりに活用しない不規則動詞があります。よく使う動詞ほど不規則で、tener（持つ）、ir（行く）、hacer（する）のほか、quiero（querer）、puedo（poder）のように語幹の母音が変わる動詞も、毎日の会話に欠かせません。

不規則動詞は数が多く見えますが、ほとんどはいくつかのパターンに分けられます。このユニットでは、マドリードで旅を続けるミナが、注文したり、許可を求めたり、予定を話したりする場面を例に、パターンごとに覚えていきます。

## 文法：現在形の不規則動詞 (Gramática)

不規則動詞は、大きく三つのパターンに分けられます。

### パターン1：語幹の母音が変わる動詞

強く読む語幹の母音が、e → ie、o → ue、e → i と変わります。**nosotros と vosotros だけは変わらない**のが大きな特徴です。

| 人称 | querer（e → ie） | poder（o → ue） | pedir（e → i） |
| --- | --- | --- | --- |
| yo | qu**ie**ro | p**ue**do | p**i**do |
| tú | qu**ie**res | p**ue**des | p**i**des |
| él / ella / usted | qu**ie**re | p**ue**de | p**i**de |
| nosotros / nosotras | queremos | podemos | pedimos |
| vosotros / vosotras ※ | queréis | podéis | pedís |
| ellos / ellas / ustedes | qu**ie**ren | p**ue**den | p**i**den |

同じ変化をする動詞：

- e → ie：pensar（考える）、empezar（始まる）、cerrar（閉まる）、entender（理解する）
- o → ue：dormir（眠る）、volver（戻る）、encontrar（見つける）、costar（値段が〜である：¿Cuánto cuesta?）
- e → i：pedir（頼む）、repetir（くり返す）、servir（出す・役に立つ）

### パターン2：yo だけが不規則な動詞

yo の形だけが変わり、ほかは規則どおりです。

| 動詞 | yo | tú |
| --- | --- | --- |
| hacer（する） | hago | haces |
| poner（置く） | pongo | pones |
| salir（出る） | salgo | sales |
| conocer（知っている） | conozco | conoces |
| saber（知っている） | sé | sabes |
| ver（見る） | veo | ves |
| dar（与える） | doy | das |

conocer と saber は、どちらも「知っている」と訳せますが、使い分けがあります。conocer は人や場所を、会ったり行ったりして知っていること。saber は情報や、やり方を知っていることです：Mina no conoce Madrid.（ミナはマドリードに行ったことがない）／ Mina sabe hablar un poco de español.（ミナはスペイン語を少し話せる）。

### パターン3：二つの変化が重なる動詞と、完全な不規則動詞

tener と venir は、yo が -go になり、ほかの人称では語幹の母音も変わります。ir はどのパターンにも当てはまらない、完全な不規則動詞です。

| 人称 | tener（持つ） | venir（来る） | ir（行く） |
| --- | --- | --- | --- |
| yo | tengo | vengo | voy |
| tú | tienes | vienes | vas |
| él / ella / usted | tiene | viene | va |
| nosotros / nosotras | tenemos | venimos | vamos |
| vosotros / vosotras | tenéis | venís | vais |
| ellos / ellas / ustedes | tienen | vienen | van |

### 旅先で使う表現

<Examples>

- Quiero un café con leche.（カフェ・コン・レチェが欲しいです）
- ¿Puedo pagar con tarjeta?（カードで払えますか？）
- Tengo que comprar un billete.（切符を買わなければならない）
- Mañana voy al Museo del Prado.（明日、プラド美術館に行く）

</Examples>

美術館のチケット売り場で、ミナが係の人と話します。不規則動詞がいくつ出てくるか、数えてみましょう。

- Mina: Hola, buenos días. Quiero una entrada, por favor.（こんにちは。入場券を1枚ください）
- Empleado: Muy bien. Son doce euros.（かしこまりました。12ユーロです）
- Mina: ¿Puedo pagar con tarjeta?（カードで払えますか？）
- Empleado: Sí, claro.（ええ、もちろん）
- Mina: ¿A qué hora cierra el museo?（美術館は何時に閉まりますか？）
- Empleado: Cierra a las ocho.（8時に閉まります）

quiero（querer）、puedo（poder）、cierra（cerrar）の三つは、どれも語幹の母音が変わる動詞です。

**tener を使う表現**も覚えておきましょう。日本語では「〜です」と言う場面でも、スペイン語では「〜を持っている」と考えます。

- 年齢：Mina tiene veintiocho años.（ミナは28歳です）
- 体の状態：Tengo hambre / sed / calor / frío.（お腹がすいた／のどがかわいた／暑い／寒い）
- 義務：tener que + 動詞の原形（〜しなければならない）

**ダニエル（バレンシア出身）のひとこと：** スペインでは「写真を撮る」を hacer fotos と言います（Mina hace muchas fotos.）。中南米では tomar fotos の方がふつうです。どちらも通じますが、スペインで hacer fotos と言えると、ぐっと自然に聞こえます。

## 発音・正書法 (Pronunciación y ortografía)

語幹母音の変化でできる ie と ue は、それぞれ一つの音節として、まとめて強く読みます。quiero は「キエ・ロ」の2音節で、**キエ**を強く、puedo は「プエ・ド」の2音節で、**プエ**を強く読みます。「キ・エ・ロ」と3つに分けないのがコツです。

## 日本人がよく間違える

- **nosotros まで母音を変える。** ×quieremos、×puedemos → ○**queremos**、○**podemos**。語幹母音が変わるのは、強く読む位置が語幹にある形だけです。
- **yo を規則どおりに作る。** ×Yo teno、×Yo haco、×Yo sabo → ○**tengo**、○**hago**、○**sé**。よく使う動詞の yo の形は、そのまま覚えましょう。
- **年齢を ser で言う。** ×Soy 28 años. → ○**Tengo** 28 años. 日本語の「28歳です」につられないように注意しましょう。

## 文化メモ (Referentes culturales)

<CultureNote>

スペインのバルでは、注文に poner（置く）を使うのがふつうです。¿Me pones una caña, por favor?（生ビールを一杯もらえる？）は、直訳すると「私に一杯置いてくれる？」。カウンターで店の人に tú で話しかけるのも、よくあることです。ビールと一緒に出てくる小皿の楽しみ方は、[タパス文化完全ガイド](/food/tapas/)で紹介しています。

</CultureNote>

## 練習 (Procedimientos de aprendizaje)

### 練習1：どのパターン？

次の yo の形は、どのパターンの不規則動詞ですか（e → ie / o → ue / e → i / yo だけ不規則）。

1. quiero
2. puedo
3. pido
4. hago
5. salgo
6. duermo

<details>
<summary>答えを見る</summary>

1. e → ie（querer）
2. o → ue（poder）
3. e → i（pedir）
4. yo だけ不規則（hacer）
5. yo だけ不規則（salir）
6. o → ue（dormir）

</details>

### 練習2：穴埋め

（ ）の動詞を、主語に合わせた現在形にしてください。

1. Yo (tener) ______ 28 años.
2. Mina (querer) ______ un café.
3. Nosotros (poder) ______ pagar con tarjeta.
4. ¿Tú (ir) ______ al museo?
5. Yo (hacer) ______ muchas fotos.
6. El museo (cerrar) ______ a las ocho.

<details>
<summary>答えを見る</summary>

1. tengo
2. quiere
3. podemos（nosotros は母音が変わらない）
4. vas
5. hago
6. cierra（e → ie）

</details>

## まとめ

- 語幹母音が変わる動詞（quiero, puedo, pido）は、nosotros と vosotros だけ変わらない。
- yo だけ不規則な動詞（hago, salgo, sé）と、tener・venir・ir は形ごと覚える。
- 年齢・空腹・暑さ寒さは tener、「〜しなければならない」は tener que + 原形。
