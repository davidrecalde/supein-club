スペイン語のコロケーション（colocaciones）とは、tomar una decisión（決断する）や prestar atención（注意を払う）のように、ある語と自然に結びつく決まった語の組み合わせのことです。文法的には正しくても、×hacer una decisión や ×pagar atención のような組み合わせは、ネイティブには不自然に聞こえます。

C1 では、言いたいことが伝わるだけでなく、「その言い方が自然かどうか」も評価されます。このユニットでは、カルメン先生の授業の会話を例に、動詞＋名詞、形容詞＋名詞、副詞＋形容詞の代表的なコロケーションを学びます。

## 文法：コロケーション (Gramática)

まず動詞と名詞の組み合わせを、次に程度を強める形容詞と副詞を、最後にコロケーションの調べ方を見ていきましょう。

### 動詞＋名詞

もっとも大切なのは、名詞と結びつく動詞です。日本語や英語から直訳すると、違う動詞を選んでしまいがちです。

| 動詞 | コロケーション | 意味 |
| --- | --- | --- |
| tomar | tomar una decisión / tomar medidas / tomar nota | 決断する／対策をとる／メモする |
| hacer | hacer una pregunta / hacer caso / hacer cola | 質問する／言うことを聞く／列に並ぶ |
| dar | dar un paseo / dar la razón / dar importancia | 散歩する／（相手が）正しいと認める／重視する |
| poner | poner en marcha / poner fin a | 始動させる／終止符を打つ |
| llevar | llevar a cabo | 実行する |
| echar | echar una siesta / echar de menos | 昼寝をする／恋しく思う |
| そのほか | prestar atención / cometer un error / correr un riesgo / desempeñar un papel / sacar una conclusión | 注意を払う／過ちを犯す／危険を冒す／役割を果たす／結論を出す |

日本語の「注意を払う」は prestar（貸す）、「危険を冒す」は correr（走る）と、動詞の意味だけでは予想できない組み合わせが多くあります。一つずつ、名詞とセットで覚えましょう。

### 形容詞＋名詞：程度を強める

「とても大きい」と言いたいとき、muy grande のかわりに、名詞ごとに決まった形容詞を使うと、表現がぐっと自然になります。

<Examples>

- una lluvia torrencial（豪雨）
- un éxito rotundo（大成功）
- un fuerte dolor de cabeza（激しい頭痛）
- un profundo respeto（深い敬意）
- un problema grave（深刻な問題）

</Examples>

名詞＋de＋名詞の組み合わせもあります：una ola de calor（熱波）、una lluvia de críticas（批判の嵐）、un ataque de nervios（ひどく取り乱すこと）、un golpe de suerte（思いがけない幸運）。

### 副詞＋形容詞

改まった文章では、muy のかわりに形容詞と結びつく副詞を使います。

| 副詞＋形容詞 | 意味 |
| --- | --- |
| profundamente agradecido | 心から感謝している |
| sumamente importante | きわめて重要な |
| rotundamente falso | まったくの誤りである |
| altamente recomendable | 強くおすすめできる |
| plenamente consciente | 十分に自覚している |

### コロケーションの調べ方

自然な組み合わせかどうか迷ったら、コロケーションの辞典（Ignacio Bosque の『REDES』など）を引くか、RAE の CORPES XXI で、その組み合わせが実際の文章でどれくらい使われているかを検索してみましょう。例文が多く見つかる組み合わせほど、自然な言い方です。

### カルメン先生の授業で

- Alumno: Tengo que hacer una decisión importante.（大事な決断をしなければならないんです）
- Carmen: Se dice «tomar una decisión». Y, por cierto, también se dice «cometer un error», no «hacer un error».（「tomar una decisión」と言うのよ。ついでに言うと、「hacer un error」ではなく「cometer un error」ね）
- Alumno: ¡Uf! El inglés me juega malas pasadas.（うわあ、英語のせいでよく失敗します）
- Carmen: Es normal. Presta atención a qué verbo acompaña a cada sustantivo y tómalo como una sola palabra.（よくあることよ。名詞ごとにどの動詞がつくかに注意して、一つの語として覚えなさい）

Carmen の言葉にも、prestar atención と tomar（〜を…として受けとめる）が使われています。jugar una mala pasada（ひどい目にあわせる）も、会話でよく使うコロケーションです。

**ダニエル（バレンシア出身）のひとこと：** コロケーションには地域差もあります。スペインでは「恋しい」を echar de menos と言いますが、中南米では extrañar がふつうです。また、「バスに乗る」はスペインでは coger el autobús、中南米の多くの地域では tomar el autobús と言います。どちらの地域のスペイン語で話しているかを意識しましょう。

## 活用：今日の動詞 (Conjugación)

コロケーションでは、tomar、[dar](/language/learn-spanish/verb-conjugation/dar/)、[hacer](/language/learn-spanish/verb-conjugation/hacer/) のような基本動詞が、もとの意味を薄めて使われます。dar の点過去（di、dio）と hacer の点過去（hice、hizo）は不規則なので、活用表で確認しておきましょう：Tomé una decisión. / Di un paseo. / Hice una pregunta.

## 発音・正書法 (Pronunciación y ortografía)

コロケーションは一つの語のように、つなげて読みます。子音で終わる語のあとに母音で始まる語が続くと、子音が次の母音とくっついて一つの音節になります：tomar una decisión（ト・マ・ル・ナ・デ・シ・シ**オン**）、hacer una pregunta（ア・セ・ル・ナ・プレ・**グン**・タ）。単語ごとに区切って読むより、ずっと自然に聞こえます。

## 日本人がよく間違える

- **英語の make につられて hacer を使う。** ×hacer una decisión → ○**tomar** una decisión ／ ×hacer un error → ○**cometer** un error
- **日本語の「払う」を pagar にする。** ×pagar atención → ○**prestar** atención
- **何でも muy で強める。** △un éxito muy grande → ○un éxito **rotundo** ／ △muy agradecido（改まった手紙）→ ○**profundamente** agradecido

## 文化メモ (Referentes culturales)

<CultureNote>

食べ物にも決まった組み合わせがあります。マドリードの定番といえば chocolate con churros（チョコレートとチュロス）で、この順番で言うのがふつうです。チュロスは濃厚なホットチョコレートに mojar（浸す）して食べ、朝食やおやつのほか、夜遊びの締めくくりにも食べられています。1894年にはマドリードで最初のチュロス専門店が開業したという記録もあるそうです。スペインの伝統菓子は、[スペイン伝統菓子ガイド](/food/spanish-desserts/)で紹介しています。

## まとめ

- コロケーションは、名詞と動詞を一つのセットで覚える：tomar una decisión、prestar atención、cometer un error、llevar a cabo。
- 程度は muy のかわりに、名詞・形容詞ごとの決まった語で強める：éxito rotundo、lluvia torrencial、profundamente agradecido。
- 迷ったら、コロケーション辞典や CORPES XXI で、実際に使われているかを確かめる。
