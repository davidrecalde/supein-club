スペイン語の por と para は、どちらも日本語の「〜のために」「〜で」などにあたるため、日本人が最も迷う前置詞の組み合わせです。大まかに言うと、para は目的・行き先・期限など「向かう先」を、por は理由・通る場所・手段など「その原因や経路」を表します：Estudio para aprobar.（合格するために勉強する）／ No fui por la lluvia.（雨のせいで行かなかった）。

一つずつの用法を覚えるより、「矢印の先（para）」と「通り道・原因（por）」のイメージで考えるとわかりやすくなります。このユニットでは、留学生活で忙しいユイと、マドリードへ移動するケンタの例を使って学びます。

## 文法：por と para (Gramática)

まず para の使い方を、次に por の使い方を、最後に por を使った決まった表現を見ていきましょう。

### para：向かう先

| 用法 | 意味 | 例 |
| --- | --- | --- |
| 目的 | 〜するために | Estudio español para trabajar en España. |
| 行き先 | 〜へ・〜行きの | El autobús para Madrid sale a las ocho. |
| 期限 | 〜までに | Tengo que entregar el trabajo para el lunes. |
| 受け取る人 | 〜あての・〜のための | Este regalo es para ti. |
| 意見 | 〜にとって | Para mí, el español es más fácil que el inglés. |
| 比べると | 〜にしては | Para una ciudad tan pequeña, tiene mucha vida. |

### por：理由・通り道・手段

| 用法 | 意味 | 例 |
| --- | --- | --- |
| 理由・原因 | 〜のせいで・〜のおかげで | No fui a clase por la lluvia. |
| 通る場所・あたり | 〜を通って・〜のあちこちを | Paseamos por el centro. |
| 手段 | 〜で | Te lo envío por correo. |
| 交換・代価 | 〜と引き換えに | Pagué veinte euros por el libro. |
| おおよその時 | 〜ごろ・〜に | Te llamo por la tarde. |
| 受動態の行為者 | 〜によって | El cuadro fue pintado por Goya. |

目的の para と理由の por は、意味が近いので特に注意しましょう。para は「これから起こすこと」、por は「すでにある原因」です：Trabajo para ganar dinero.（お金を稼ぐために働く）／ Lo hice por ti.（君のためを思ってやった：君が理由）。

### por を使った決まった表現

por favor（お願いします）、gracias por（〜をありがとう）、por ejemplo（たとえば）、por fin（やっと）、por cierto（ところで）、por eso（だから）は、まとめて覚えましょう。

### ユイの忙しい一週間

Esta semana estoy muy ocupada. Tengo que entregar un trabajo para el lunes y estudiar para el examen del viernes. Por la mañana voy a clase y por la tarde trabajo en una cafetería para pagar el alquiler. Por cierto, el sábado viene Kenta. Va a venir en autobús por la autopista desde Madrid.

（今週はとても忙しいです。月曜日までにレポートを提出しなければならないし、金曜日の試験の勉強もしなければなりません。午前中は授業に出て、午後は家賃を払うためにカフェで働いています。ところで、土曜日にケンタが来ます。マドリードから高速道路を通るバスで来る予定です）

### por と para のよく使う表現

ほかにも、決まった形で覚えておきたい表現があります。para siempre（永遠に）、para nada（全然〜ない：¿Te molesta? — Para nada.）、por lo menos（少なくとも）、por supuesto（もちろん）、por todas partes（いたるところに）。

- Kenta: ¿Te molesta si abro la ventana?（窓を開けてもいい？）
- Yui: Para nada. Por cierto, ¿has comido? Hay comida para todos.（全然かまわないよ。ところで、食べた？みんなの分の料理があるよ）

一つの会話の中に、para nada、por cierto、para todos が自然に入っています。

意味の違いがわかりやすい組み合わせも見ておきましょう。Lo hago por ti.（君のためを思ってやる：君が理由）と Lo hago para ti.（君にあげるために作る：受け取る人）。Trabajo para una empresa japonesa.（日本の会社で働いている：勤め先）と Trabajo por mi familia.（家族のために働いている：理由）。同じ「〜のために」でも、理由なら por、目的や受け取る人なら para です。

旅行の予定を言うときは、Salgo para Sevilla el lunes y paso por Córdoba.（月曜日にセビリアへ出発して、コルドバを通る）のように、行き先は para、通る場所は por で言い分けます。

por favor（お願いします）の por も、もとは「好意によって」という意味の por です。

**ダニエル（バレンシア出身）のひとこと：** 迷ったら、para には「→（矢印の先）」、por には「〜を通って・〜が原因で」というイメージを思い出してください。たとえば、tren para Madrid は「マドリードに着く電車」、tren por Madrid は「マドリードを通る電車」です。

## 活用：今日の動詞 (Conjugación)

por と para は、どの時制の文にも出てきます。このユニットの例文では、ir（voy、va a venir）や tener（tengo que）がよく使われています。[ir](/language/learn-spanish/verb-conjugation/ir/) と [tener](/language/learn-spanish/verb-conjugation/tener/) の活用表で、現在形と点過去を確認しておきましょう。

## 発音・正書法 (Pronunciación y ortografía)

por と para は、会話ではとても弱く速く発音されます。para は、くだけた会話では pa と短くなることがあります：Voy pa casa.（家に帰る）。聞き取りでは知っておくと便利ですが、書くとき、特に試験では必ず para と書きましょう。

## 日本人がよく間違える

- **目的に por を使う。** ×Estudio español por trabajar en España. → ○Estudio español **para** trabajar en España.
- **期限に por を使う。** ×Tengo que entregarlo por el lunes. → ○Tengo que entregarlo **para** el lunes.
- **感謝に para を使う。** ×Gracias para todo. → ○Gracias **por** todo.

## 文化メモ (Referentes culturales)

## 練習 (Procedimientos de aprendizaje)

### 練習1：por？ para？

正しい方を選んでください。

1. Este regalo es (por / para) mi madre.
2. Gracias (por / para) la cena.
3. Salgo (por / para) Madrid mañana.
4. Paseamos (por / para) la playa.
5. Lo necesito (por / para) el viernes.
6. Lo envié (por / para) correo.

<details>
<summary>答えを見る</summary>

1. para（受け取る人）
2. por（感謝の理由）
3. para（行き先）
4. por（通る場所）
5. para（期限）
6. por（手段）

</details>

### 練習2：用法を答える

次の文の por / para は、どの用法ですか（目的・理由・期限・通る場所・交換・意見）。

1. No salimos por el frío.
2. Para mí, es la mejor ciudad.
3. Cambié mi móvil por uno nuevo.
4. Ahorro para viajar.

<details>
<summary>答えを見る</summary>

1. 理由（寒さのせいで）
2. 意見（私にとって）
3. 交換（新しいのと交換した）
4. 目的（旅行するために貯金する）

</details>
