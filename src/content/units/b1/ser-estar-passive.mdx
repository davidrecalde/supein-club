スペイン語の ser と estar は、A1 で学んだ「性質と状態」の区別に加えて、過去分詞と組み合わせると違う働きをします。ser + 過去分詞は「〜される」という受動態（La catedral fue construida en el siglo XVI.、大聖堂は16世紀に建てられた）、estar + 過去分詞は「〜されている」という結果の状態（La biblioteca está cerrada.、図書館は閉まっている）です。

さらに、だれがするかを言わない一般的なことは、se を使って Se habla inglés.（英語が通じます）と言います。このユニットでは、サラマンカの歴史を案内するユイと、出張の合間に観光するケンタの場面を例に、ser と estar の応用を学びます。

## 文法：ser と estar の応用、受動態 (Gramática)

ser と estar の基本の使い分け（国籍・職業と、状態・場所）は、[ユニット3「ser と estar の違い」](/language/learn-spanish/a1/ser-estar/)で確認できます。

まず ser の受動態を、次に estar の結果の状態を、最後に se の受け身と、意味が変わる形容詞を見ていきましょう。

### ser + 過去分詞：受動態

「（だれかによって）〜される・された」と、行為そのものを表します。行為をした人は por で示します。過去分詞は主語の性と数に合わせます。

<Examples>

- Este cuadro fue pintado por Velázquez.（この絵はベラスケスによって描かれた）
- La catedral fue construida en el siglo XVI.（大聖堂は16世紀に建てられた）

</Examples>

受動態は、建物や作品の歴史を説明する文、ニュースや案内の文でよく使います。会話では、能動態（Velázquez pintó este cuadro.）の方が自然なことも多いです。

### estar + 過去分詞：結果の状態

行為のあとに残っている状態を表します。

| ser（行為） | estar（状態） |
| --- | --- |
| La tienda fue cerrada por la policía.（店は警察に閉鎖された） | La tienda está cerrada.（店は閉まっている） |
| La ventana fue rota por un niño.（窓は子どもに割られた） | La ventana está rota.（窓が割れている） |

### se を使った受け身

だれがするかを言わず、一般的なことを言うときは、se + 3人称の動詞を使います。動詞は物の数に合わせます。

| 形 | 例 |
| --- | --- |
| se + 3人称単数 | Se habla inglés.（英語が通じます） |
| se + 3人称複数 | Se venden pisos.（マンション売ります） |
| se + 3人称単数（人一般） | Aquí se come muy bien.（ここはおいしいものが食べられる） |

お店の看板や案内には、この形がたくさん出てきます：Se alquila habitación.（部屋貸します）、Se prohíbe fumar.（禁煙）。

### ser と estar で意味が変わる形容詞

| 形容詞 | ser | estar |
| --- | --- | --- |
| listo | 賢い | 準備ができた |
| rico | 金持ちの | （食べ物が）おいしい |
| aburrido | 退屈な（性質） | 退屈している（状態） |
| malo | 悪い（性質） | 体調が悪い |

<Examples>

- ¡Esta tortilla está muy rica!（このトルティージャ、すごくおいしい！）
- ¿Estás lista? Nos vamos.（準備できた？行くよ）

</Examples>

### サラマンカを案内する

ユイが、サラマンカを訪れたケンタを案内します。

Esta es la universidad. Fue fundada en el siglo XIII y es una de las más antiguas de España. Con la visita, se puede ver la biblioteca histórica. En esta plaza se come muy bien y los precios son buenos.

（これが大学です。13世紀に創設された、スペインで最も古い大学の一つです。見学をすると、歴史的な図書館も見ることができます。この広場ではおいしいものが食べられて、値段も手ごろです）

### se を使った一般的な言い方

se は受け身のほかに、「人は一般に〜する」という意味でも使います：Se dice que Salamanca es la ciudad más bonita de Castilla.（サラマンカはカスティーリャでいちばん美しい町だと言われている）、En España se cena tarde.（スペインでは夕食が遅い）、¿Se puede pagar con tarjeta?（カードで払えますか）。日本語の「〜と言われている」「（一般に）〜する」にあたり、ガイドブックやお店でとてもよく見かけます。

estar casado（結婚している）、estar sentado（座っている）、estar cansado（疲れている）のように、日本語の「〜している」の多くは estar + 過去分詞で言います。ユニット11の進行形（estar + 現在分詞）と混同しないようにしましょう。

ニュースの見出しでは、ser を省いて過去分詞だけを書くこともあります：Inaugurado el nuevo museo.（新しい美術館が開館）。

**ダニエル（バレンシア出身）のひとこと：** 料理をほめるときの ¡Está riquísimo! は、スペインの食卓で一番よく聞く言葉かもしれません。ser を使って ¡Es rico! と言うと「（この料理は）お金持ちだ」のようなおかしな意味になるので、味には必ず estar を使ってください。

## 活用：今日の動詞 (Conjugación)

受動態では [ser](/language/learn-spanish/verb-conjugation/ser/) の点過去（fue、fueron）が、結果の状態では [estar](/language/learn-spanish/verb-conjugation/estar/) の現在形（está、están）が中心です。活用表で ser の点過去を確認しておきましょう。過去分詞の不規則な形（roto、hecho、escrito、abierto）も、受動態や結果の状態でよく使います。

## 発音・正書法 (Pronunciación y ortografía)

世紀はローマ数字で書き、読むときはふつうの数字で読みます：el siglo XVI（エル・**シ**グロ・ディエシ**セイ**ス）、el siglo XIII（エル・**シ**グロ・**トレ**セ）。日本語の「16世紀」と違って、siglo（世紀）が数字の前に来ます。

## 日本人がよく間違える

- **受動態の過去分詞を主語に合わせない。** ×La catedral fue construido. → ○La catedral fue **construida**.
- **閉まっている・壊れている状態に ser を使う。** ×La tienda es cerrada. → ○La tienda **está** cerrada.
- **se の受け身で動詞の数を合わせない。** ×Se vende pisos. → ○Se **venden** pisos.

## 練習 (Procedimientos de aprendizaje)

### 練習1：ser？ estar？

正しい方を選んでください。

1. La catedral (fue / estuvo) construida en el siglo XVI.
2. La tienda (es / está) cerrada hoy.
3. ¡Esta paella (es / está) muy rica!
4. Mi hermano (es / está) muy listo; siempre saca buenas notas.
5. Hoy no voy a trabajar; (soy / estoy) malo.

<details>
<summary>答えを見る</summary>

1. fue（受動態）
2. está（結果の状態）
3. está（味）
4. es（賢い）
5. estoy（体調が悪い）

</details>

### 練習2：穴埋め

（ ）の動詞を、指示に合わせた形にしてください。

1. El cuadro fue (pintar) ______ por Goya.
2. Las puertas están (abrir) ______.
3. Aquí se (hablar) ______ español e inglés.
4. Se (vender) ______ bicicletas.
5. La ventana está (romper) ______.
6. Las casas fueron (construir) ______ en 1950.

<details>
<summary>答えを見る</summary>

1. pintado
2. abiertas（abrir の過去分詞は不規則）
3. habla
4. venden（bicicletas は複数）
5. rota（romper の過去分詞は不規則）
6. construidas

</details>

### 練習3：作文

スペイン語で言ってみましょう。

2. 図書館は日曜日は閉まっている。
3. このトルティージャ、すごくおいしい！

<details>
<summary>解答例を見る</summary>

2. La biblioteca está cerrada los domingos.
3. ¡Esta tortilla está muy rica!

</details>

## まとめ

- ser + 過去分詞（+ por）は受動態、estar + 過去分詞は結果の状態。過去分詞は主語に性数を合わせる。
- だれがするかを言わない一般的なことは se + 3人称（Se habla inglés. / Se venden pisos.）。
- listo・rico・aburrido・malo は、ser と estar で意味が変わる。
